## 3. 本期 MVP 技术栈
- 后端：FastAPI + Uvicorn，SQLite 存储
- 鉴权：自研 JWT（HMAC-SHA256）无状态
- 智能体：Tool / IntentRouter / Agent / Memory + 可插拔 LLMAdapter
- 知识库：JSON 版本化（meta.version / effective_date / sources）
- 前端：双端静态 HTML + Fetch/SSE
