# 02c 干系人与角色分工

> 编号：02c ｜ 类别：项目基本简报（共 4 份）

## 1. 角色与职责
| 角色 | 职责 | 使用端 | 演示账号 |
|---|---|---|---|
| 会员 | 权益持有者，出示核销码由门店核销 | 会员端（微信小程序，已有） | member01 |
| 收银员 / 门店员工 | 现场核验权益、代生成核销码、核销计价、转人工 | 员工端 | employee01 / Employee@123456 |
| 运营管理员 | 维护权益知识库、发版、处理转人工、查看审计 | 管理端 | manager01 / Manager@123456 |
| 店长 | 监督门店核销合规、查看概览 | 管理端（只读视角） | — |
| 智能体项目组 | 需求调研、设计、MVP 开发、交付文档 | 开发侧 | — |

## 2. 关键协作流
1. **日常核验**：会员出示码 → 员工端核验计价 → 完成核销（审计落库）。
2. **规则维护**：运营在管理端 upsert 规则 → 审批后 publish 发版 → 知识库版本更新。
3. **异常处理**：现场遇退货/解释冲突 → 员工端一键转人工 → 管理端处理台跟进 → 关闭。
4. **审计回溯**：任意查询/核销/发版事件在审计看板可追溯来源与版本。

## 3. 权责边界
- 员工端**只能**做核验与转人工，不能改规则。
- 规则变更**只能**由管理端发版，且需版本号与生效日期。
- 任何人不得绕过审计链直接放行异常。
