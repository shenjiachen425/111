# 02b 项目范围与边界

> 编号：02b ｜ 类别：项目基本简报（共 4 份）

## 1. 项目范围内（本期 MVP 交付）
| 模块 | 内容 |
|---|---|
| 员工端（/employee） | 权益查询助手（精准问答 + 来源/版本标注）、代生成核销码、核销计价、转人工队列 |
| 管理端（/manager） | 经营概览、知识库 CRUD、知识库发版（upsert→publish）、审计看板、转人工处理台 |
| 知识库 | 版本化（version/effective_date/sources）、alias 匹配、按意图检索、快照发版 |
| Agent 框架 | Tool / IntentRouter / Agent / Memory / 可插拔 LLMAdapter，结构化 AgentResult |
| 工程 | FastAPI + Uvicorn + SQLite，JWT 无状态鉴权，SSE 流式 |
| 券种 | 满200减30、8.5折会员折扣、5元抵用、兑换券A（赠品券）共 4 类 |

## 2. 项目范围外（本期不做，预留接口）
- 真实大模型接入（已预留 `LLMAdapter` 接口，当前为规则检索）。
- 向量检索 / RAG（已预留接入点）。
- 线上支付、会员积分体系、多门店多租户隔离。
- 小程序会员端完整商城（本期仅收银端核销 + 管理端运维）。

## 3. 边界与红线（不可逾越）
| 红线 | 说明 |
|---|---|
| RED-1 单一事实源 | 一切权益解释以**版本化知识库**为准，前端/人工不得自行解释。 |
| RED-2 高风险强制转人工 | 退货类、追回类、解释冲突类一律**暂停并转人工**，不得自动放行。 |
| RED-3 最小权限 | 员工端不可访问管理端接口，越权/无 token 一律 401。 |
| RED-4 可审计不可篡改 | 核销、转人工、发版等写操作进入审计看板，不可删除。 |

## 4. 验收基线与口径
- 量化指标（投诉、核验时效）以**上线后实测基线**为准，不预设系统已达标。
- 一致性率等未确认数字一律标注"待测定/验收前提"，不编造。
